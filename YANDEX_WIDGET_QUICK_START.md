## 🚀 Быстрый запуск

### 1. Запуск через Docker Compose

```bash
# Из корневой директории проекта
docker-compose up -d orderservice client-storefront
```

### 2. Локальный запуск (для разработки)

**Backend (orderservice):**
```bash
cd orderservice
./gradlew bootRun
```

**Frontend (client-storefront):**
```bash
cd client-storefront
npm install  # Если еще не установлены зависимости
npm run dev
```

### 3. Открыть в браузере

```
http://localhost:3001/checkout
```

## 🧪 Как протестировать

### Шаг 1: Добавьте товары в корзину
- Перейдите на главную страницу: `http://localhost:3001`
- Добавьте любой товар в корзину

### Шаг 2: Перейдите к оформлению
- Нажмите на иконку корзины
- Нажмите "Оформить заказ"

### Шаг 3: Заполните форму
- Введите данные получателя:
  - Имя: `Иван`
  - Фамилия: `Иванов`
  - Телефон: `+7 999 123 4567`
  - Email: `ivan@example.com`
  - Адрес: `Москва, ул. Ленина, 1`

### Шаг 4: Выберите доставку
- Выберите любой способ доставки
- Ниже появится виджет Яндекс.Доставки

### Шаг 5: Работа с виджетом
- На карте отобразятся доступные ПВЗ
- Кликните на любой пункт выдачи
- Нажмите кнопку "Выбрать" в виджете
- Информация о выбранном ПВЗ отобразится под виджетом

### Шаг 6: Оформите заказ
- Выберите способ оплаты
- Нажмите "Подтвердить заказ"
- Данные выбранного ПВЗ будут сохранены в заказе

## ⚠️ Возможные проблемы

### Виджет не загружается

**Проблема:** Белый экран или спиннер загрузки
**Решение:**
1. Проверьте консоль браузера
2. Убедитесь что orderservice запущен
3. Проверьте `/api/yandex-delivery/config`

### ПВЗ не отображаются

**Проблема:** Карта пустая
**Решение:**
1. Проверьте API токен в `application.yml`
2. Проверьте `source-platform-station`
3. Проверьте логи orderservice

### Ошибка CORS

**Проблема:** CORS ошибки в консоли
**Решение:**
1. Убедитесь что `@CrossOrigin(origins = "*")` есть в контроллере
2. Перезапустите orderservice

### API токен недействителен

**Проблема:** 401/403 ошибки
**Решение:**
1. Проверьте токен: `y0__xCd-KvSCBix9Bwgp8OMiRapyG8u0V5lGR_NrN_ay2g-CTuTww`
2. Обратитесь в поддержку Яндекс.Доставки
